# Prompts de los recursos visuales

Los dos recursos se generaron con la herramienta integrada de generación de imágenes. La captura proporcionada se utilizó únicamente como referencia de atmósfera; el halcón, la composición y los detalles técnicos son originales.

## Banner

```text
Use case: stylized-concept
Asset type: original wide hero banner for a GitHub profile README, approximately 4:1 panoramic composition
Primary request: create a completely original monochrome cyberpunk banner inspired only by the reference image's dark editorial atmosphere, halftone texture, and generous negative space
Input images: Image 1 is a mood and layout reference only; do not reproduce its imagery, composition, characters, or artwork
Scene/backdrop: near-black graphite background with a subtle terminal grid and sparse code-like geometric traces
Subject: an abstract peregrine falcon formed from luminous white monospaced glyph fragments, thin circuit lines, and controlled pixel dithering; the falcon is in motion and dissolves into a clean terminal cursor trail
Style/medium: high-end black-and-white digital engraving mixed with pixel art and halftone stippling; crisp, restrained, professional
Composition/framing: very wide horizontal banner, focal subject offset slightly left of center, breathable negative space, safe margins, readable at small GitHub README width
Lighting/mood: nocturnal, technical, quietly confident
Color palette: black, charcoal, white, with one very subtle electric-cyan accent line
Constraints: no text, no letters that form readable words, no logos, no watermark; keep the design original and employment-profile appropriate
Avoid: Michelangelo hands, reaching hands, astronauts, humanoid figures, chrome portraits, direct copying of Image 1, busy collage, gradients that reduce contrast
```

## Avatar

```text
Use case: stylized-concept
Asset type: square GitHub profile avatar that visually belongs to the generated banner
Primary request: create an original emblematic portrait of a peregrine falcon head, not a human, built from crisp white halftone pixels and a few precise circuit-line details
Input images: Image 1 is the generated project banner and is a style/color reference; preserve its black, white, graphite, and subtle electric-cyan visual language
Scene/backdrop: deep black circular-friendly background with a faint technical grid
Subject: centered falcon head in three-quarter view, strong recognizable silhouette, intelligent and calm rather than aggressive
Style/medium: premium monochrome cyberpunk engraving, pixel dithering, minimal circuitry, sharp at tiny icon sizes
Composition/framing: square 1:1, centered, generous safe margin for GitHub's circular crop, face occupies about 65% of canvas
Lighting/mood: high contrast, nocturnal, quietly confident
Color palette: black, graphite, white, one tiny electric-cyan eye/circuit accent
Constraints: no text, no logos, no watermark, no humans; simple enough to remain legible at 40px
Avoid: chrome humanoids, skulls, masks, busy background, photorealistic wildlife photo, excessive neon, direct copying of any existing logo
```
